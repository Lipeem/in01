Montar · Setup

Montando o estúdio no Windows

Este é o roteiro para quem vai montar (você), feito uma vez no computador da Exposul. Reserve uma tarde. No fim, o dono só precisa abrir o Claude, jogar material na pasta e aprovar no celular.

O que você vai precisar em mãos: login do Instagram da Exposul (conta profissional já vinculada à Página do Facebook), e-mail da empresa, cartão para as assinaturas, acesso de administrador ao Windows e cerca de 4 horas.

No Buffer, conecte o Instagram em Channels › Connect › Instagram, escolhendo a conta profissional vinculada ao Facebook. Instale o app do Buffer no celular do dono: é por ele que ele vai aprovar.

Etapa 2. Programas no Windows

Claude Desktop: baixe pelo site, não pelo winget

Baixe o instalador em claude.com/download. No Windows, o Cowork só funciona no pacote .msix. Quem instala pelo instalador .exe antigo recebe o Claude Desktop sem Cowork. O pacote do winget oferece os dois formatos, por isso não use o winget para o Claude.

O Cowork também precisa de virtualização ligada no computador e do recurso do Windows Plataforma de Máquina Virtual. Se o Cowork não aparecer depois de instalar:

  1. Menu Iniciar › "Ativar ou desativar recursos do Windows" › marque Plataforma de Máquina Virtual › OK › reinicie.
  2. Se continuar sem Cowork, a virtualização está desligada na BIOS. No Gerenciador de Tarefas › Desempenho › CPU, veja se "Virtualização" está "Habilitado". Se não estiver, ligue na BIOS (o nome varia: Intel VT-x, AMD-V, SVM). Na dúvida, peça ajuda a um técnico.

Fonte: documentação de instalação do Claude Desktop (claude.com/docs). Conferido em 21/10/2026.

Ferramentas de vídeo

Abra o PowerShell (menu Iniciar › digite "PowerShell") e rode um comando por vez. O winget já vem no Windows 10 e 11 atualizados.

winget install Git.Git
winget install OpenJS.NodeJS.LTS
winget install Gyan.FFmpeg
winget install Python.Python.3.12

Feche e abra o PowerShell de novo e confira se tudo instalou:

git --version
node --version
ffmpeg -version
python --version
  • Atalho: depois da Etapa 3, dá para pedir ao Claude Code "verifique se Node 22+, FFmpeg, Python e Git estão instalados e instale o que faltar com winget".
  • Node precisa ser versão 22 ou mais nova para o HyperFrames.
  • Fontes da marca: baixe Archivo e Bodoni Moda em fonts.google.com e instale (botão direito › Instalar para todos os usuários). O ffmpeg e o HyperFrames usam as fontes instaladas.

Etapa 3. Claude Desktop e Claude Code

  1. Abra o Claude Desktop e entre com a conta Pro.
  2. Em Configurações › Capacidades, ligue execução de código. Sem isso as Skills não funcionam.
  3. Instale o Claude Code. No PowerShell: 
    irm https://claude.ai/install.ps1 | iex
    Alternativa: winget install Anthropic.ClaudeCode. O Claude Code também abre dentro do próprio app Desktop, na aba de código, sem terminal.
  4. Teste: no PowerShell, rode claude, faça login e pergunte "que versão do ffmpeg está instalada?". Ele deve rodar o comando e responder.
  5. Instale as ferramentas de legenda e recorte: peça ao Claude Code "instale faster-whisper e rembg com pip". O faster-whisper é mais leve que o Whisper original num computador sem placa de vídeo dedicada.

Cuidado com cobrança por fora. Se existir no Windows uma variável de ambiente chamada ANTHROPIC_API_KEY, o Claude Code passa a usar essa chave e cobra pela API, em vez de usar a cota do plano Pro. Para conferir, rode no PowerShell echo $env:ANTHROPIC_API_KEY: tem de voltar vazio. Fonte: Central de Ajuda do Claude.

Etapa 4. Pasta de produção

Crie C:\Exposul-Social (ou dentro do Google Drive para computador, se quiser tarefas com o PC desligado). Use a pasta modelo que está no repositório em guia-social-media/kit/pasta-modelo/Exposul-Social, ou crie à mão:

Exposul-Social\
  CLAUDE.md               instruções fixas para o Claude Code
  00-pauta\               calendário da semana e roteiros
  01-brutos\              material original (nunca editar aqui)
    videos\  fotos\  depoimentos\  lojas\<nome-da-loja>\
  02-em-edicao\           rascunhos de trabalho do Claude
  03-para-aprovar\        cada peça pronta numa subpasta
  04-aprovados\           o dono move para cá o que aprovou
  05-publicados\          arquivo do que já foi agendado
  99-marca\               logo, fontes, trilhas, dados-confirmados.md, autorizacoes.md
  1. Copie o CLAUDE.md do kit para a raiz da pasta. O texto completo está em Prompts e Skills.
  2. Em 99-marca\, coloque o logo em PNG com fundo transparente, a paleta e o arquivo dados-confirmados.md. Preencha com o dono: só o que estiver nesse arquivo pode virar post (preço, prazo, parcelamento).
  3. Despeje o acervo em 01-brutos\. Organize as lojas montadas numa pasta por loja, com nome e cidade: lojas\moda-ana-joinville\.

Etapa 5. Skill "marca-exposul"

  1. Pegue a pasta guia-social-media/kit/marca-exposul do repositório (ou copie o texto em Prompts e Skills para um arquivo SKILL.md dentro de uma pasta marca-exposul).
  2. Compacte a pasta em ZIP (botão direito › Compactar).
  3. No Claude Desktop: Personalizar › Skills › + › Enviar e escolha o ZIP.
  4. Para o Claude Code, copie também a pasta para C:\Exposul-Social\.claude\skills\marca-exposul\. Versões recentes do Claude Code também sincronizam as skills da conta.
  5. Teste no chat: "Escreva uma legenda para um Reel de antes e depois de uma loja de calçados em Chapecó." A resposta deve seguir o formato da skill, com CTA e até 5 hashtags.

Etapa 6. Conectores

No Claude Desktop, vá em Personalizar › Conectores.

ConectorComo adicionarPermissão das ferramentas de escrita

CanvaDiretório › "Canva" › ConectarSempre perguntar
Google DriveDiretório › "Google Drive"Sempre perguntar
HyperFramesDiretório › "HyperFrames"Pode permitir
Higgsfield+ Adicionar › Conector personalizado › nome "Higgsfield", URL https://mcp.higgsfield.ai/mcp › loginSempre perguntar (gasta crédito)
ElevenLabsDiretório › "ElevenLabs"Sempre perguntar

Para o Claude Code usar os mesmos serviços, rode na pasta de produção:

cd C:\Exposul-Social
claude mcp add --transport http buffer https://mcp.buffer.com/mcp
claude mcp add --transport http higgsfield https://mcp.higgsfield.ai/mcp

Depois, dentro do claude, digite /mcp e faça o login de cada um.

No Cowork, deixe o modo de aprovação em Manual. Assim nenhum post vai para o Buffer sem alguém clicar em permitir.

Etapa 7. Motion graphics (HyperFrames)

Duas formas. Comece pela primeira.

  1. Conector (etapa 6): renderiza na nuvem da HeyGen, sem instalar nada. Bom para vinhetas, títulos animados e encerramento com logo. Está em beta.
  2. Local, pelo Claude Code: claude plugin marketplace add heygen-com/hyperframes, depois claude plugin install hyperframes@hyperframes, e confira com npx hyperframes doctor. Detalhes no README em github.com/heygen-com/hyperframes. Grátis e sem limite de renders. O suporte a Windows não está declarado não verificado: se der erro, fique com o conector.

Peça ao Claude Code para criar 3 modelos e salvar em 99-marca\motion\: abertura com gancho (2 s), lista animada de 3 itens, encerramento com logo e CTA (2 s). Os vídeos da semana reaproveitam esses modelos.

O Remotion faz o mesmo com mais recursos, mas exige licença paga para empresa com mais de 3 pessoas (US$ 25 por assento/mês).

Etapa 8. Primeiro teste de ponta a ponta

  1. Coloque um vídeo de montagem de loja em 01-brutos\lojas\teste\.
  2. No Claude Code, dentro de C:\Exposul-Social, use o prompt "Editar um Reel" de Prompts.
  3. Confira a pasta em 03-para-aprovar\: vídeo 9:16 com legenda embutida, capa, legenda.txt, alt.txt e ficha.md.
  4. Mova para 04-aprovados\ e peça: "Envie a peça aprovada para o Buffer como rascunho."
  5. No app do Buffer, confira se chegou como Reel, com capa e legenda. Repita com um carrossel de 5 fotos.

Se o vídeo não subir pelo conector (a documentação do Buffer não deixa claro como o MCP recebe arquivo local), use o plano B: o Claude deixa tudo pronto em 04-aprovados\ e o dono sobe no app do Buffer ou do Instagram, copiando a legenda do legenda.txt. Leva cerca de 2 minutos por post. Outra saída é testar o Postiz, cujo MCP tem ferramentas próprias de mídia.

Etapa 9. Automação de DM

  1. No computador, abra o Meta Business Suite › Caixa de entrada › Automações.
  2. Crie uma automação por palavra-chave: comentário ou DM com VITRINE recebe a mensagem abaixo.
  3. Repita para LOJA, CABIDE e MANEQUIM, cada uma com o link certo.
Oi! Aqui é o atendimento automático da Exposul 😊
Aqui está o catálogo: [link do catálogo]
Pra uma pessoa da equipe continuar com você: sua loja é de qual segmento e em qual cidade?
Se preferir, fala direto com a gente no WhatsApp: (41) 99691-0019

A mensagem diz que é automática de propósito: o cliente sabe que vai falar com uma pessoa em seguida, e isso evita a irritação com robô que a maioria dos brasileiros relata. Regras da Meta e LGPD em Estratégia › Regras e cuidados.

Os nomes de menu da Meta mudam com frequência. Se não achar, os tutoriais de ManyChat em Vídeos mostram a mesma lógica.

Etapa 10. Perfil da Empresa no Google

A Exposul já tem 4,8 estrelas com 315 avaliações, mas o perfil tem dados errados. Corrija no business.google.com (detalhes em Reputação):

  • Horário de sábado igual ao do site (o Google mostra "fechado").
  • Bairro Rebouças e telefone fixo como adicional.
  • Descrição citando entrega em todo o Brasil e montagem de loja.
  • Copiar o link curto e baixar o QR code de avaliação (Ler avaliações › Receber mais avaliações, só no computador).
  • Publicar um post: os últimos são de maio e serão arquivados em novembro.

Etapa 12. Passagem para o dono (30 minutos)

  • Mostre a rotina semanal e onde fica cada pasta.
  • Faça com ele, ao vivo, uma aprovação no app do Buffer.
  • Mostre o checklist de gravação para a equipe (em Roteiros).
  • Combine quem responde DM e comentário, e em quanto tempo.
