# Guia de social media com IA — Exposul

Mini-site estático (abra `index.html` no navegador) com diagnóstico, estratégia,
linha editorial, roteiros, frequência, ferramentas, setup no Windows, prompts,
rotina semanal, vídeos do YouTube e fontes. Pesquisa de 21/10/2026.

`kit/` traz os arquivos prontos para o estúdio:
- `marca-exposul/SKILL.md` — skill de marca para subir no Claude (compactar a pasta em ZIP)
- `CLAUDE.md` — instruções fixas do Claude Code na pasta de produção
- `calendario-modelo.csv` — planilha de pauta e resultados
- `pasta-modelo/Exposul-Social/` — estrutura de pastas para copiar para `C:\`
